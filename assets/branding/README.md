# Organization branding

GitHub `OSSCA-chromium` 조직 프로필에 사용할 이미지의 SVG 원본과 PNG를 보관합니다.

| 파일                                                                 | 용도                                   |
| -------------------------------------------------------------------- | -------------------------------------- |
| [ossca-chromium-org-icon.svg](ossca-chromium-org-icon.svg)           | 크기와 여백을 조정할 수 있는 벡터 원본 |
| [ossca-chromium-org-icon-2048.png](ossca-chromium-org-icon-2048.png) | 조직 프로필에 업로드할 2048×2048 PNG   |

- 기존 Chromium 마크의 도형과 색상을 유지합니다.
- 사방에 약 10%씩 투명 여백을 두어 로고가 전체 폭의 80%를 차지합니다.
- PNG는 SVG 원본에서 2048×2048 크기로 내보냅니다.
- 적용할 때는 GitHub 조직 설정에서 PNG를 프로필 이미지로 업로드합니다.

사이트 favicon은 [`src/app/icon.svg`](../../src/app/icon.svg)에서 별도로 관리합니다.
