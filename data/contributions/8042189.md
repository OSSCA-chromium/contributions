Origin Lit 전환 이후 보안 웹 테스트 8개의 기대 결과를 갱신하고, 성공과 실패를 모두 허용하던 임시 설정을 제거했습니다.

## 문제 설명

CL 8038580에서는 Origin Lit 전환을 위해 보안 웹 테스트 8개의 기대값을
임시로 조정했습니다. 변경이 Chromium에 반영된 뒤에는 새 DOM 출력에 맞게
기대 결과를 갱신하고, 정상적인 검증 기준으로 되돌려야 했습니다.

## 해결 내용

- 테스트 8개의 `-expected.txt`에 Lit 주석 노드와 아이콘 주변 요소 구조의
  변경을 반영했습니다.
- 작업 중 반영된 CL 8069249의 UI 문구 변경도 기대 결과에 포함했습니다.
  예를 들어 `Network Panel`이 `Network panel`로 바뀐 내용을 반영했습니다.
- `TestExpectations`에서 관련 `[ Failure Pass ]` 항목 8개와 주석을 제거했습니다.

## 테스트 방법

CL에 기록한 테스트는 다음과 같습니다.

```bash
third_party/blink/tools/run_web_tests.py http/tests/devtools/security/
```

리뷰 과정에서 추가 UI 문구 변경에 따른 tryjob 실패를 확인하고 기대 결과를
갱신했습니다. 최종적으로 CQ를 거쳐 2026년 7월 16일(한국 시간)
Chromium main에 병합되었습니다.

## 배운 점

- 기대 결과를 갱신할 때는 DOM 구조뿐 아니라, 작업 중 반영된 UI 문구 변경도
  함께 확인해야 합니다.
- 임시로 조정한 기대값을 제거해야 이후의 예상 밖의 실패를 다시 검출할 수 있습니다.
