`Certificate Transparency section`의 Lit 전환을 위해 보안 웹 테스트 2개의 기대값을 임시 조정했습니다.

## 문제 설명

CL 8426420의 DOM 변경으로 보안 웹 테스트 2개가 기존 기대 결과와 달라졌습니다.

## 해결 내용

`TestExpectations`에 `[ Failure Pass ]`를 추가해 해당 테스트의 성공과 실패를
모두 허용했습니다. 후속 CL 8449930에서 기대 결과를 갱신하고 이 설정을 제거했습니다.

## 테스트 방법

최종 patchset의 CQ 실행은 통과했으며, 2026년 9월 23일(한국 시간)
Chromium main에 병합되었습니다.

## 배운 점

리뷰에서 반복적인 병합 충돌을 줄이기 위해 기대값 항목을 파일 끝이 아닌
중간에 추가하도록 안내받아 반영했습니다.
