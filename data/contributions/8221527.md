Element 가 focus 변경 시점에 활성화된 iframe 으로 요소가 이동하게 되는 케이스에 대한 Crash Test 추가(WPT)

## 문제 설명

1. 선행 이슈(CL 2873191): 포커스 헤제 이벤트 발생 시, 해당 엘리먼트가 분리된 별개의 문서(비활성화)로 이동하게 되는 특수한 상황에 대한 크래시 테스트가 추가 됨
2. 이에 저자 Mason Freed 는 focus 요소가 현 문서(this) 에 존재하지 않을 경우 자연스럽게 return 하는 분기로 이를 해결 -> 추가로 활성화 된 문서로의 요소 이동에 대한 크래시 테스트 필요.
(active iframe 내 adoptNode 후 SetFocusedElement 내 crash test)

## 해결 내용

1. 간략하게 위 해결해야 하는 문제 상황대로 script 를 작성함
    ```html
    <script>
    const root = document.documentElement;

    const activeIframe = document.createElement("iframe");
    root.appendChild(activeIframe);

    const targetIframe = document.createElement("iframe");
    root.appendChild(targetIframe);

    targetIframe.addEventListener("focusout", () => {
        activeIframe.contentDocument.adoptNode(targetIframe);
    })

    targetIframe.focus();

    const nextTarget = document.createElement("button");
    root.appendChild(nextTarget);

    nextTarget.focus();
    </script>
    ```

2. 추가적인 수정사항 수정

    - 큰 의미없는 if 분기처리 삭제
    - nextIframe -> nextTarget 으로 불필요한 iframe 삭제


## 테스트 방법

content-shell, image-diff 빌드 이후, run_web_tests.py 실행 결과 no crash
