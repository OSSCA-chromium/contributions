`metadata/others/histograms.xml` 에서 기록 코드가 없어진 히스토그램 9개와, 공용 `enums.xml` 에서 이것만 쓰던 enum 5개를 지웠습니다. 9개 중 2개는 만료일이 `never` 라 obsoletion 메시지에 기록 코드가 사라진 근거를 적었습니다. 2파일 −178, XML 만 바꾸는 CL 입니다. `metadata/others` OWNER jonross@ 가 먼저 승인했고, 히스토그램 정리 작업을 해 온 meiliang@ 이 9개와 enum 5개의 삭제와 폐기 태그를 확인해 두 번째로 승인했습니다. meiliang@ 의 CQ 로 2026-10-07(UTC)에 머지됐습니다([773aa4584be8d](https://crrev.com/773aa4584be8d64313b5b2d99397d145d74f53e5)).

## 문제 설명

- 공식 정리 작업 메타 버그: https://crbug.com/499059525
- `FirstRun.NewUserExperience.*` 4개는 chrome://welcome 페이지의 TS 코드만 기록했는데 [crrev.com/c/6054055](https://crrev.com/c/6054055)에서 페이지와 함께 사라졌습니다. 2개는 2025-04 만료, 2개는 `never` 였습니다.
- `Drive.PushNotificationRegistered`([crrev.com/c/6341611](https://crrev.com/c/6341611)), `Mojo.Connector.MaxUnreadMessageQuotaUsed`([crrev.com/c/4093879](https://crrev.com/c/4093879)), `Ozone.NeuralStylusReport.ActivePalmTouchCount`([crrev.com/c/4547040](https://crrev.com/c/4547040)), `TouchScreen.MissedTOUCHEVENTF_UP`([crrev.com/c/6003551](https://crrev.com/c/6003551)), `Tracing.SharedBufferIsValid`([crrev.com/c/6078882](https://crrev.com/c/6078882))도 기록 코드가 지워진 지 1~4년 된 항목입니다.

## 해결 내용

- 9항목과 전용 enum `NuxGoogleAppsInteractions`·`NuxLandingPageInteractions`·`NuxNtpBackgroundInteractions`·`NuxSetAsDefaultInteractions`·`BooleanRegistered` 를 지웠습니다. `BooleanHit`·`BooleanSuccess` 는 다른 히스토그램이 많이 써서 남겼습니다.
- 만료되지 않은(`never`) 2개는 README 가 요구하는 대로 obsoletion 메시지에 사유(chrome://welcome 삭제 CL)를 적었습니다.
- 공식 histogram-cleanup 형식(`[histogram-cleanup]` 제목, 해시태그, `Bug: 499059525`)을 따랐습니다. 폐기 태그는 같은 날 올린 8523097 의 리뷰 지적에 따라 리뷰 전에 히스토그램별 단수형 `OBSOLETE_HISTOGRAM[이름]` 으로 고쳤습니다(만료된 7개는 `=expired`, `never` 2개는 사유 메시지).

## 발굴 과정

«기록 코드가 하나도 없는 만료 히스토그램» 스캔에서 `metadata/others` 로 모인 묶음입니다. 디렉터리 OWNER 한 명이 전부 승인할 수 있고, 공용 `enums.xml` 은 `per-file enums.xml=*` 라 누구나 승인할 수 있습니다. 항목마다 형제 히스토그램(패턴 이름, `never` 만료 포함)까지 함께 확인해 반쪽 정리가 되지 않게 했습니다.

## 테스트 방법

- `validate_format.py` 통과, `pretty_print.py --presubmit` 변경 없음, `git cl format` 변경 없음
- `git cl presubmit --upload` 통과
- XML 만 바뀌어 빌드와 단위 테스트는 해당 없음

## 배운 점

- `expires_after="never"` 인 히스토그램도 기록 코드가 사라졌으면 정리 대상입니다. 다만 만료분과 달리 obsoletion 메시지에 근거를 남겨야 합니다.
- 공용 `enums.xml` 의 enum 은 사용처가 여러 디렉터리에 흩어져 있어, 지우기 전에 전체 XML 에서 사용 수를 세어야 합니다.
