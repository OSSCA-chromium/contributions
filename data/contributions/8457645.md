Chromium의 `blocked-mixed-content.js`를 DevTools unit test로 옮겼습니다.
차단된 mixed content의 설명과 request 링크가 Security panel에 표시되는지 검증합니다.

## 문제 설명

기존 테스트는 mixed content 설명의 DOM 출력을 기대 결과와 비교해, DOM 구조 변경에도
기대 결과 갱신이 필요했습니다. 이를 unit test로 옮겨 설명과 request 링크를 직접 검증하도록 했습니다.

## 해결 내용

- `SecurityPanel.test.ts`에 unit test 1개를 추가했습니다.
- 기존 테스트와 같은 security state 이벤트를 전달하고, mixed content로 차단된
  `Blockable` request의 `RequestFinished` 이벤트를 전달했습니다.
- 설명이 하나이며 `security-explanation-info` class를 갖는지 확인했습니다.
- `Blocked mixed content` 제목, 차단 안내 문구, `View 1 request in Network panel`
  링크 문구와 `role="link"`를 검증했습니다.

기존 Chromium 테스트와 기대 결과 파일의 제거는 후속 CL 8457503에서 진행했습니다.
