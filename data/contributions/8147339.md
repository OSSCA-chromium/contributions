지원이 종료된 LaCrOS를 UI 용어집에서 제거했습니다.

## 문제 설명

LaCrOS는 [CL 5862339](https://crrev.com/c/5862339)에서 지원 종료 상태가
문서에 반영되었고, 이후 [CL 5892904](https://crrev.com/c/5892904)에서
`docs/lacros.md`를 포함한 관련 문서들이 삭제되었습니다.

그러나 `docs/ui/learn/glossary.md`에는 LaCrOS 설명과 삭제된
`/docs/lacros.md` 링크가 남아 있는 상태였습니다.

## 해결 내용

처음에는 링크를 제거하고 항목을 deprecated로 표시하도록 작업했지만,
리뷰어 요청에 따라 UI 용어집에서 LaCrOS 항목 전체를 제거했습니다.

`docs/ui/learn/glossary.md`

```diff
-### LaCrOS
-
-An abbreviation for "Linux And Chrome OS". An architecture project to decouple
-the Chrome browser on Chrome OS from the operating system stack; historically
-these were tightly coupled and updated simultaneously.
-[More general background on LaCrOS](/docs/lacros.md)
-
```

## 테스트 방법

Gitiles에서 LaCrOS 항목이 제거된 것을 확인했습니다.

## 배운 점

- 관련 내용의 변경 이력과 맥락을 충분히 확인해야 한다는 점을 배웠습니다.
- 대체할 유효한 내용이 없다면 오래된 항목을 제거하는 방법도 고려해야 한다는
  점을 배웠습니다.
