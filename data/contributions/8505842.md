components/device_signals에서 쓰던 `crypto/sha2.h`의 `crypto::SHA256HashString()`을 `crypto/hash.h`의 `crypto::hash::Sha256()`으로 migration했습니다. 2파일 +6/−4.

## 문제 설명

- issue url: https://crbug.com/372283556
- //crypto 모듈은 `sha2.h`, `secure_hash.h`를 제거하고 `hash.h`로 옮기는 작업을 진행 중입니다.
- components/device_signals의 mac, win platform delegate가 인증서 SPKI의 SHA-256 해시를 구할 때 아직 `crypto::SHA256HashString()`을 사용하고 있었습니다.

## 해결 내용

1. `mac_platform_delegate.mm`, `win_platform_delegate.cc`의 `#include "crypto/sha2.h"`를 `#include "crypto/hash.h"`로 바꿨습니다.
2. `crypto::SHA256HashString()`은 `std::string`을 반환하지만 `crypto::hash::Sha256()`은 고정 길이 바이트 배열을 반환합니다. 호출부가 계속 `std::string`을 기대하므로 `base::as_string_view()`로 감싼 뒤 `std::string`으로 변환했습니다.
3. win 쪽은 `base::as_string_view()`를 쓰기 위해 `base/strings/string_view_util.h` include를 추가했습니다. mac 쪽은 이미 include되어 있었습니다.

```diff
-  public_keys.hashes.push_back(crypto::SHA256HashString(spki_bytes));
+  public_keys.hashes.push_back(
+      std::string(base::as_string_view(crypto::hash::Sha256(spki_bytes))));
```

```diff
-      ret.first = crypto::SHA256HashString(spki);
+      ret.first = std::string(base::as_string_view(crypto::hash::Sha256(spki)));
```
