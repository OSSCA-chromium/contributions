Chromium의 `mixed-content-reload.js`를 DevTools unit test로 옮겼습니다.
request가 기록되면 mixed content의 reload 안내가 Network panel 링크로 바뀌는지 검증합니다.

## 문제 설명

기존 테스트는 request 기록 전후의 DOM 출력을 기대 결과와 비교해, DOM 구조 변경에도
기대 결과 갱신이 필요했습니다. 이를 unit test로 옮겨 안내 문구의 전환을 직접 검증하도록 했습니다.

## 해결 내용

- `SecurityPanel.test.ts`에 unit test 1개를 추가했습니다.
- `displayed-mixed-content` 상태를 전달한 뒤 reload 안내가 표시되는지 확인했습니다.
- 같은 security state 이벤트를 다시 전달하고, `OptionallyBlockable` request의
  `RequestFinished` 이벤트를 전달했습니다.
- 안내가 `View 1 request in Network panel` 문구와 `role="link"`를 갖는 링크로
  바뀌는지 검증했습니다.
- request 기록 전후에 설명이 하나이며, 상태 class·제목·본문이 유지되는지도 확인했습니다.
