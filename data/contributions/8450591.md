DevTools unit test로 옮긴 CL 8450050의 후속 작업으로, 기존 Chromium의
`blank-origins-not-shown` 웹 테스트와 기대 결과 파일을 제거했습니다.

## 문제 설명

blank origin이 Security sidebar에 표시되지 않는지 확인하는 검증을 DevTools로
옮긴 뒤에도, 같은 시나리오를 검사하는 기존 Chromium 웹 테스트가 남아 있었습니다.

## 해결 내용

`third_party/blink/web_tests/http/tests/devtools/security/`에서
`blank-origins-not-shown.js`와 `blank-origins-not-shown-expected.txt`를 제거했습니다.
해당 동작의 검증은 CL 8450050에서 추가한 `SecurityPanel.test.ts`의 unit test가
담당합니다.

## 테스트 방법

최종 patchset의 CQ 실행은 통과했으며, 2026년 9월 24일(한국 시간)
Chromium main에 병합되었습니다.

## 배운 점

테스트 migration은 새 테스트 추가와 기존 테스트 제거를 함께 확인해야 합니다.
기존 입력과 검증 내용을 옮긴 뒤 테스트 파일과 기대 결과 파일을 함께 정리했습니다.
