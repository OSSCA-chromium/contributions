제목 영역의 Lit 전환 CL 8289248을 반영할 수 있도록, Chromium 보안 웹 테스트
4개가 일시적으로 성공과 실패를 모두 허용하도록 기대값을 조정했습니다.

## 문제 설명

CL 8289248은 제목 영역의 DOM 출력을 바꾸므로, 기존 출력과 비교하는
Chromium 보안 웹 테스트 4개가 실패했습니다. DevTools 변경을 병합하고
Chromium에 반영된 뒤 기대 결과를 갱신할 수 있도록 임시 설정이 필요했습니다.

## 해결 내용

`third_party/blink/web_tests/TestExpectations`에 다음 네 테스트의 기대값을
`[ Failure Pass ]`로 추가했습니다.

- `http/tests/devtools/security/origin-view-ct-compliance.js`
- `http/tests/devtools/security/origin-view-noncryptographic-secure-origin.js`
- `http/tests/devtools/security/origin-view-then-interstitial.js`
- `http/tests/devtools/security/security-details-updated-with-security-state.js`

테스트 실행을 건너뛰는 `Skip`이 아니라, 일시적으로 성공과 실패를 모두 허용하는
설정입니다. 관련 CL과 버그 번호를 명시했으며, 후속 CL 8399066에서 기대 결과를
갱신하고 이 임시 설정을 제거했습니다.

## 테스트 방법

Gerrit에 기록된 CQ 실행 통과 결과와 최종 병합 상태를 확인했습니다.
2026년 9월 10일(한국 시간) Chromium main에 병합되었습니다.

## 배운 점

- 별도 저장소의 UI 변경을 반영할 때는 영향을 받는 테스트와 변경 순서를
  확인해야 합니다.
- 임시 기대값에 관련 CL과 버그 번호를 남기면 후속 작업에서 제거할 대상을
  확인하기 쉽습니다.
