VS Code에서 deprecated로 표시된 `vscode-proto3`를 대체 확장인 `Protobuf VSC`로 교체했습니다.

## 문제 설명

Chromium의 VS Code 가이드와 추천 확장 설정에 deprecated된 `vscode-proto3`가 남아 있었습니다.

## 해결 내용

- `docs/vscode.md`의 확장 이름과 Marketplace 링크를 `Protobuf VSC`로 변경했습니다.
- `tools/vscode/extensions.json`의 확장 ID를 `zxh404.vscode-proto3`에서
  `DrBlury.protobuf-vsc`로 변경했습니다.

전체 코드 diff는 다음과 같습니다.

## 테스트 방법

병합된 커밋에서 문서의 링크와 추천 설정이 같은 확장 ID를 사용하는지 확인했습니다.

CQ를 통해 2026년 6월 4일(한국 시간) Chromium main에 병합되었습니다.

## 배운 점

개발 도구를 교체할 때는 안내 문서와 실제 추천 설정을 함께 갱신해야 합니다.
