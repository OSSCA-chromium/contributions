SAN 표시의 Lit 전환을 반영할 수 있도록, Chromium 보안 웹 테스트 2개가
일시적으로 성공과 실패를 모두 허용하도록 기대값을 조정했습니다.
DevTools 변경이 Chromium에 반영된 뒤 기대 결과를 갱신하고 임시 설정을
제거하는 작업을 후속 CL로 진행했습니다.

## 문제 설명

SAN 표시를 Lit으로 전환한 CL 8045801은 DOM 구조를 바꾸므로,
기존 DOM 출력과 비교하는 Chromium 보안 웹 테스트의 기대 결과도 달라집니다.
DevTools 변경을 먼저 병합하고 Chromium에 반영된 뒤 기대 결과를 갱신할 수
있도록 두 저장소의 변경 시점을 조율할 필요가 있었습니다.

## 해결 내용

`third_party/blink/web_tests/TestExpectations`에 다음 두 테스트의 기대값을
`[ Failure Pass ]`로 추가했습니다.

- `http/tests/devtools/security/origin-view-ct-compliance.js`
- `http/tests/devtools/security/security-details-updated-with-security-state.js`

테스트 실행을 건너뛰는 `Skip`이 아니라, 일시적으로 성공과 실패를 모두
허용하는 설정입니다. 주석에 SAN Lit 전환 CL을 연결했으며,
후속 CL 8140384에서 기대 결과를 갱신하고 이 임시 설정을 제거했습니다.

## 테스트 방법

CL에 기록한 테스트는 다음과 같습니다.

```bash
third_party/blink/tools/run_web_tests.py http/tests/devtools/security/
```

2026년 7월 21일 Chromium main에 병합되었습니다.

## 배운 점

- 다른 저장소의 UI 변경을 반영할 때는 영향을 받는 테스트를 확인하고,
  기대값 임시 조정과 기대 결과 갱신 순서를 정해야 합니다.
- 기대값을 임시 조정할 때는 관련 CL을 명시하고, 후속 작업에서 해당 설정을
  제거해야 합니다.
