SecurityOriginView의 안내 문구 영역을 Lit으로 전환하고, 표시 조건과 캐시 안내
테스트를 추가했습니다. 인증서 투명성 영역이 표시되지 않을 때 일반 안내 문구도
누락되던 문제를 함께 수정했습니다.

## 문제 설명

기존 코드는 SCT가 없고 CT 준수 여부가 Unknown이면 생성자에서 바로 반환해,
뒤에 있는 일반 안내 문구 영역도 생성하지 않았습니다. 보안 상세 정보가 있어도
첫 번째로 검사한 응답의 정보라는 안내와 캐시 안내가 누락될 수 있었습니다.

## 해결 내용

- `renderNoteSection()`에서 캐시 안내와 첫 번째로 검사한 응답에 대한 안내를
  Lit 템플릿으로 렌더링하도록 했습니다.
- CT 영역을 생략할 때 생성자에서 반환하던 코드를 바꿔, 해당 영역만 조건부로
  생성하도록 했습니다. 보안 상세 정보가 있으면 CT 영역 표시 여부와 관계없이
  일반 안내 문구를 표시합니다.
- `loadedFromCache`가 참이면 캐시 안내를 먼저 표시하고, 보안 상세 정보가
  없으면 일반 안내 영역을 생성하지 않는 조건은 유지했습니다.
- 기존 CT 테스트의 일반 안내 영역 부재 검증을 제거하고, 안내 영역의
  단위 테스트 7개를 추가했습니다.

## 테스트 방법

`SecurityPanel.test.ts`에 다음 내용을 검증하는 단위 테스트 7개를 추가했습니다.

- 보안 상세 정보가 있으면 일반 안내 문구를 표시하고, null이면 영역을 생략하는지 확인
- 캐시 응답이면 캐시 안내와 일반 안내를 순서대로 표시하는지 확인
- SCT 목록에 항목이 있으면 안내 영역을 표시하는지 확인
- CT 준수 여부가 Unknown, Compliant, NotCompliant인 세 경우 모두 안내 영역을 표시하는지 확인

Chromium 웹 테스트 `security-details-updated-with-security-state.js`의 기대값은
CL 8458524에서 임시 조정했습니다. 최종 patchset의 CQ 실행이 통과했으며,
2026년 9월 28일(한국 시간) DevTools main에 병합되었습니다.

## 배운 점

- 한 영역을 생략하기 위한 조기 반환이 뒤에 있는 다른 영역까지 생략하는지
  확인해야 합니다.
- 독립적으로 표시해야 하는 영역은 각각의 조건으로 렌더링하고, 표시 조건의
  조합을 테스트로 검증해야 합니다.
