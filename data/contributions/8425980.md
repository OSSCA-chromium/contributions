CSSWG 결정에 따라 `::marker`에서 `quotes` 속성을 지원하도록 했습니다.

## 문제 설명

기존에는 `::marker`에 직접 지정한 `quotes`가 적용되지 않아, `content`의
`open-quote`와 `close-quote`에 해당 따옴표가 반영되지 않았습니다.
이로 인해 `marker-quotes.html` WPT가 실패했습니다.

## 해결 내용

- `css_properties.json5`의 `quotes` 정의에 `valid_for_marker: true`를 추가했습니다.
- `::marker`에 지정한 `quotes`의 computed value를 확인하는 테스트를 추가했습니다.
- animation·transition 테스트에 `quotes` 항목을 추가했습니다.
- `marker-quotes.html`의 `[ Failure ]` 기대값을 제거했습니다.

## 테스트 방법

CL에 기록한 검증 대상은 다음 WPT 3개입니다.

- `external/wpt/css/css-lists/marker-quotes.html`: marker별 따옴표 렌더링
- `external/wpt/css/css-pseudo/parsing/marker-supported-properties.html`: computed value
- `external/wpt/css/css-pseudo/parsing/marker-supported-properties-in-animation.html`:
  animation·transition에서의 속성 적용

CQ를 통해 2026년 9월 30일(한국 시간) Chromium main에 병합되었습니다.

## 배운 점

CSS 속성을 pseudo-element에서 지원하려면 속성 정의의 적용 범위도 확인해야 합니다.
렌더링 결과와 함께 computed style 및 animation·transition 경로를 검증해야 합니다.
