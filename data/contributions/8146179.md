docs/speed/speed_domains.md의 깨진 메일링 리스트 링크를 수정하고, 같은 파일의 레거시 형식 링크를 현대화한 컨트리뷰션입니다.

## 문제 설명

- binary-size 메일링 리스트 링크가 `https` 스킴이 유실된 채 작성되어 렌더링 시 깨짐
    - `[Mailing List](://groups.google.com/a/chromium.org/forum/#!forum/binary-size)`
- 2017년 문서 최초 작성 시점부터 깨진 상태로 존재. 한 번도 유효한 적 없던 링크

## 해결 내용

1. 깨진 링크를 최신 그룹 URL 형식으로 교체
    - `https://groups.google.com/a/chromium.org/g/binary-size`
    - 구 `forum/#!forum/` 형식은 클라이언트 리다이렉트에 의존하는 폐기된 문법
    - 최근 docs/에 새로 추가되는 그룹 링크는 전부 `/g/` 형식인 것 확인
2. 같은 파일의 나머지 메일링 리스트 링크 2건(memory-dev, loading-dev)도 일관성을 위해 `/g/`로 함께 현대화
3. 첫 컨트리뷰션이라 `AUTHORS`에 이름·이메일 추가 (같은 커밋에 포함)

## 테스트 방법

1. `/g/` URL 3건 모두 유효성 검증 (존재하지 않는 그룹명을 대조군으로 응답 코드 비교)
2. `tools/md_browser`로 로컬 렌더링 확인, 링크 3건 모두 정상 앵커로 렌더링
3. `docs/` 전체에 동일 유형(`](://`)의 깨진 링크가 더 없는 것 확인

## 배운 점

- Gerrit 계정 이메일과 git 커밋 이메일이 일치해야 push 가능 (불일치 시 invalid committer로 거부)
- 첫 CL에는 AUTHORS 등록이 필요하고, 누락 시 presubmit 경고 발생
- 파일 히스토리를 추적해 깨진 시점과 원인 CL을 찾는 과정에서 Gitiles 로그와 Code Search 활용법을 익힘
