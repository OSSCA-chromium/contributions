Origin 표시의 Lit 전환을 반영할 수 있도록, Chromium 보안 웹 테스트 8개가 일시적으로 성공과 실패를 모두 허용하도록 기대값을 조정했습니다.

## 문제 설명

Origin 표시를 Lit으로 전환한 CL 7969697은 DOM 구조를 바꾸므로,
기존 DOM 출력과 비교하는 Chromium 보안 웹 테스트의 기대 결과도 달라집니다.
DevTools 변경이 Chromium에 반영되기 전까지 두 저장소의 변경 시점을 조율할
필요가 있었습니다.

## 해결 내용

`third_party/blink/web_tests/TestExpectations`에 관련 테스트 8개의
기대값을 `[ Failure Pass ]`로 추가했습니다. 테스트 실행을 건너뛰는 `Skip`이
아니라, 일시적으로 성공과 실패를 모두 허용하는 설정입니다.

주석에 Lit 전환 CL을 연결했으며, 변경이 Chromium에 반영된 뒤
CL 8042189에서 기대 결과를 갱신하고 이 임시 설정을 제거했습니다.

## 테스트 방법

CL에 기록한 테스트는 다음과 같습니다.

```bash
third_party/blink/tools/run_web_tests.py http/tests/devtools/security/
```

CQ를 거쳐 2026년 7월 3일 Chromium main에 병합되었습니다.

## 배운 점

- 별도 저장소의 UI 변경을 반영할 때는 기존 테스트 기대 결과와 맞지 않는 기간을
  고려해, 기대값 조정과 후속 갱신 순서를 정해야 합니다.
- 기대값을 임시 조정할 때는 관련 CL을 명시하고, 후속 작업에서 원래의 검증 기준으로
  되돌려야 합니다.
