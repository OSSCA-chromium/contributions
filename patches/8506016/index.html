[glanceables] Remove four expired Ash.Glanceables.Api.Tasks histograms

IN REVIEW2026chrome/browser/ash/api/tasksglanceableshistogramsmetrics-cleanup
2026. 10. 2.jmsmg
https://crrev.com/c/8506016

ChromeOS Glanceables(달력 옆 할 일 패널)의 Google Tasks API 클라이언트가 기록하던 개수 히스토그램 4개를 지웠습니다. 넷 모두 2025-12-31에 만료돼 더는 수집되지 않는 죽은 코드였습니다. 3파일 +2/−88.

문제 설명

  • issue url: 버그 번호 없음 (OSSCA #655)
  • tasks_client_impl.cc가 기록하는 Ash.Glanceables.Api.Tasks.{ProcessedTasksCount,RawTasksCount,SimultaneousMarkAsCompletedRequestsCount,TaskListsCount}는 expires_after="2025-12-31"이고 expired_intentionally가 아닙니다.
  • tools/metrics/histograms/README.md는 만료된 히스토그램의 기록 코드를 죽은 코드로 보고 지우라고 안내합니다.

해결 내용

  • 기록 네 곳을 지웠습니다. 두 곳은 같은 TODO 주석 아래 PagesCount 기록이 남아, 주석을 «these histograms»에서 «this histogram»으로 고쳤습니다.
  • 테스트에서 이 4개만 검사하던 문장 7개를 지웠습니다. 테스트 자체는 모두 남아 있고, 같은 테스트의 다른 히스토그램 검사도 그대로입니다.
  • histograms.xml의 4항목을 지웠습니다.
  • 같은 클래스가 기록하는 Ash.Glanceables.Api.{Method}.{Latency,PagesCount,Status}는 xml에 패턴으로 따로 정의돼 있고 Classroom 클라이언트와 공유하므로 건드리지 않았습니다.
     base::UmaHistogramCounts100(
         "Ash.Glanceables.Api.Tasks.GetTaskLists.PagesCount", page_number);
-    base::UmaHistogramCounts100("Ash.Glanceables.Api.Tasks.TaskListsCount",
-                                accumulated_raw_task_lists.size());

발굴 과정

Mac에서 ChromeOS 경로의 만료 히스토그램 후보를 뽑았고(LE), 리눅스에서 파일을 다시 읽었습니다. 처음 수정 때는 같은 파일의 Latency·Status·PagesCount 기록까지 함께 지웠는데, diff를 검토하다가 그것들이 스캔 기준(2026-01-01 이전 만료) 밖이고 Classroom과 공유하는 패턴 정의이며 «Tasks API로 일반화» TODO가 붙은 운영 지표라는 것을 확인했습니다. 승인된 범위인 4개로 되돌려 다시 적용했습니다.

테스트 방법

  • 리눅스 박스의 target_os="chromeos" 빌드(out/cros)에서 unit_tests 증분 빌드: 14 스텝 1분 46초.
  • gn check '//chrome/browser/ash/api/tasks/*', validate_format.py, pretty_print.py --presubmit 통과.
  • unit_tests --gtest_filter='TasksClientImpl*': 수정 전 36/36 → 수정 후 36/36. 테스트 이름 집합이 같은 것을 대조했습니다(테스트 삭제 없음).
  • presubmit 0 경고

배운 점

  • 한 파일 안에서도 히스토그램마다 만료일과 정의 방식(개별 항목 vs {Method} 패턴)이 다릅니다. 스캔이 뽑아 준 목록을 넘어 지우기 전에, 각 이름의 xml 정의와 만료일을 하나씩 확인합니다.
  • 코드와 histograms.xml 양쪽 OWNERS에 모두 있는 사람(chrome/browser/ash·metadata/ash의 achuith@)을 찾으면 리뷰어 한 명으로 승인을 끝낼 수 있습니다.
