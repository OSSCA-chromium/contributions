<h2 id="문제-설명">문제 설명</h2><ul>
<li><code>docs/rust/ffi.md</code> 문서에서 동일 디렉토리에 위치한 안전 가이드라인 문서(<code>unsafe.md</code>)를 참조하는 경로가 <code>docs/rust/unsafe.md#how-to-use-unsafe</code>로 작성되어 있었습니다.</li>
<li>상대 경로 기준 오류로 인해 실제 브라우저나 문서 뷰어에서는 <code>docs/rust/docs/rust/unsafe.md</code> 경로로 잘못 해석되어 404 페이지 오류(깨진 링크)가 발생하고 있었습니다.</li>
</ul>
<h2 id="해결-내용">해결 내용</h2><p>Chromium Code Search의 git blame 히스토리를 분석하고 대상 문서의 실제 위치를 파악하여 링크를 올바른 상대 경로로 수정하였습니다.</p>
<ol>
<li><p>첫 번째 접근 방법</p>
<ul>
<li>Chromium Code Search의 <a href="https://source.chromium.org/chromium/chromium/src/+/main:docs/rust/ffi.md;bpv=1;bpt=0">git blame 기능</a>을 활용하여 해당 라인의 히스토리를 파악했습니다.</li>
<li>분석 결과, 이전 문서 업데이트 과정에서 잘못된 상대 경로 링크가 추가되었음을 확인하였습니다. (<a href="https://source.chromium.org/chromium/chromium/src/+/main:docs/rust/ffi.md;bpv=1;bpt=0;drc=02c8cb9be292399d899e7968fb1150f611dba021;dlc=4dba7416560a7b258ae62fd30ec288101caf481f">변경 이력 참조</a>)</li>
<li>참조 대상인 <code>unsafe.md</code> 파일이 실제 codebase 내에 존재하는지 검색하여 검증하였고, <code>ffi.md</code>와 동일한 디렉토리(<code>docs/rust/</code>)에 있는 파일을 가리키려 했던 의도임을 파악하였습니다.</li>
</ul>
