1a:T67c2,<p>SecurityOriginView의 <code>certificate section</code>을 Lit으로 전환했습니다. certificate details 표시와<br />certificate viewer를 여는 동작의 테스트를 추가했습니다.</p>
<h2 id="문제-설명">문제 설명</h2><p><code>certificate section</code>은 기존 DOM 생성 코드로 구성하고, SAN 목록만 별도로 Lit으로<br />렌더링하고 있었습니다. 인증서 정보와 SAN, 상세 보기 버튼을 하나의 Lit<br />렌더링 흐름으로 전환하는 작업입니다.</p>
<h2 id="해결-내용">해결 내용</h2><ul>
<li><code>buildCertificateDetailsRows()</code>와 <code>renderCertificateSection()</code>에서 인증서<br />제목과 상세 정보 표를 만들도록 했습니다. Subject, SAN, 유효 기간, Issuer,<br />상세 보기 버튼의 순서와 제목의 접근성 속성을 유지했습니다.</li>
<li>표의 값에 문자열뿐 아니라 Lit 템플릿도 사용할 수 있도록 확장하고,<br />SAN과 상세 보기 버튼을 템플릿으로 포함했습니다.</li>
<li><code>#createCertificateSection()</code>에서 SAN의 접힘 상태를 관리하고, 버튼 클릭 시<br /><code>certificate section</code>을 다시 렌더링하도록 했습니다. 기존 <code>#createSanDiv()</code>는 제거했습니다.</li>
<li>인증서 조회와 뷰어 호출을 <code>#showCertificateViewer</code>로 옮겼습니다.<br />조회 결과가 비어 있으면 뷰어를 호출하지 않는 동작을 유지했습니다.</li>
<li><code>certificate section</code>의 단위 테스트 5개와 테스트에 필요한 Host 의존성을 추가했습니다.</li>
</ul>
