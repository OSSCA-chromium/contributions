1a:T6280,<p>SecurityOriginView의 SAN 표시를 Lit으로 전환했습니다. devtools-button에<br />accessibleExpanded 속성을 추가하고, createSanDiv는 기존 UI와 연결하는 함수로<br />유지했습니다.</p>
<h2 id="문제-설명">문제 설명</h2><p><code>SecurityOriginView</code>는 인증서의 SAN(Subject Alternative Name) 목록을 DOM<br />생성·수정 코드로 구성하고, 목록을 펼치거나 접을 때 클래스와 버튼 상태를 직접<br />변경하고 있었습니다. 이 부분을 Lit 템플릿으로 전환하는 작업입니다.</p>
<h2 id="해결-내용">해결 내용</h2><ul>
<li><code>renderSan()</code>에서 SAN 항목과 펼치기·접기 버튼을 렌더링하도록 했습니다.<br />목록이 비어 있으면 <code>(n/a)</code>를 표시하고, 3개 이하면 모두 표시하며,<br />4개 이상이면 처음에는 2개만 표시하는 기존 동작을 유지했습니다.</li>
<li><code>#createSanDiv()</code>에서 접힘 상태를 관리하고, 버튼을 누르면 상태를 바꿔<br />다시 렌더링하도록 했습니다. 반환한 요소는 기존 UI에서 사용합니다.</li>
<li>버튼을 <code>devtools-button</code>으로 전환하고, <code>accessibleExpanded</code> 속성으로<br />내부 버튼의 <code>aria-expanded</code>를 설정할 수 있도록 했습니다.</li>
<li>SAN 표시 테스트 3개와 버튼의 <code>aria-expanded</code> 테스트 2개를 추가하고,<br />Security 패널의 빌드 설정에 버튼 컴포넌트 의존성을 추가했습니다.</li>
</ul>
