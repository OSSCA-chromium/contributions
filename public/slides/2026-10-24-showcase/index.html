사례 1 · 공통 마이그레이션

CL 8148099 safe_browsing/db: migrate to crypto/hash APIs (최민섭)

  • 문제

    //crypto 모듈이 crypto/sha2.h를 제거하고 crypto/hash.h로 이전하는 중이었고, 사용처가 여러 디렉터리에 남아 있었음

  • 해결

    Safe Browsing DB 코드의 해시 계산을 새 API로 교체. 반환 타입이 문자열에서 바이트 배열로 바뀌어 문자열이 필요한 호출부에 변환 추가

  • 공동 작업

    이슈 진행자에게 메일로 허락을 받고 팀 레포 이슈 #282로 공유. 디렉터리별 sub-issue를 만들어 멘티 11명이 나눠서 진행

11명참여 멘티

16건병합 (10/5)

사례 2 · viz 코드 정리

CL 8348446 [viz] Remove Capabilities::supports_surfaceless (김범수)

  • 문제

    같은 상태를 나타내는 플래그가 두 개 있었음. supports_surfaceless는 이름과 달리 GPU 지원 여부를 조회하지 않았고, 2019년 TODO가 달린 미사용 코드도 남아 있었음

  • 해결

    플래그를 읽는 여섯 곳이 모두 두 값이 같은 플랫폼에서만 실행되는 것을 확인하고 renderer_allocates_images로 통일

  • 후속 작업

    10주차 모임에서 viz 구조를 발표. 이후 swap 실패 시 화면에 표시 중인 오버레이가 해제되는 버그를 수정 중 (CL 8448731, 리뷰 중)

6곳플래그 사용처 확인
2019년에 작성된 TODO 정리
9/11병합 (9/19 팀 발표)

사례 3 · WPT 실패 수정

CL 8311028 [Blink] Fix capitalization after supplementary characters (박호정)

  • 문제

    text-transform: capitalize가 보충 평면 문자(이모지 등) 뒤의 단어 경계를 잘못 판단. css-pseudo WPT 1건이 Chromium에서 실패

  • 해결

    이전 문자를 UTF-16 코드 유닛 하나로 전달하던 코드를 코드 포인트 단위로 변경. 회귀 테스트를 추가하고 WPT 실패 기대값 제거

  • 리뷰 반영

    변경 동작을 런타임 플래그로 제어해 문제가 생기면 끌 수 있도록 함. 리뷰 코멘트 대응 내용은 9주차 모임에서 발표
